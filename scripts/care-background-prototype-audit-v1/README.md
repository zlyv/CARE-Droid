# CARE-Droid background Prototype audit V1

Read-only audit of the four historical frozen Direct-C43 windows and three seeds
per window. All writes remain under `outputs/care_background_prototype_audit_v1/`.
No APK extraction, new model training, checkpoint mutation or threshold tuning.

`run.sh` performs the asset preflight, source-code/shape self-test, training-window
Prototype support, cross-bank overlap, existing-signal and error-association
diagnostics, then rehashes the named baseline assets. The distances are diagnostics
on the actual shared standardized 107-dimensional input space. A KMeans center is
not an individual source Host; nearest training Host is explicitly a proxy.

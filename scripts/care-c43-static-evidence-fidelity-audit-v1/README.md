# C43 static-evidence fidelity audit v1

This is a source-2017-only, non-training audit of all 35 Direct-C43 unfixed routed errors and all 17 Direct-C43 broken cases.

It reuses the exact frozen representation replay, verified DEX fingerprints, SVM routing, and Direct-C43 predictions. It does not load future data or alter formal assets.

The automated layer trace localizes structural compression/collision. It deliberately stops short of declaring a structural difference to be benign or malicious semantics; that decision belongs to the separate blinded review form.

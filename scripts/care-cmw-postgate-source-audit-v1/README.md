# CMW post-gate source sufficiency audit v1

This independent audit reuses the 799 frozen label-free feature records produced by `care-contextual-multihop-witness-v1`.

It does not lower or reinterpret the failed 0.20 coverage gate. It asks a separate source-only question: does the observed 19.34% directed attention mass contain reproducible class-direction information?

The fixed comparisons are REAL depth-8, ONE_HOP, ROOT_SHUFFLE, degree-preserving CALLSITE_SHUFFLE, COUNT_ONLY and PATH_ONLY. All direction probes use the same fixed five-fold, side-conditional OOF protocol and the same low-capacity logistic model. No future rows, end-to-end correction or method selection are used.

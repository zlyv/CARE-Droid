# CARE-Droid R4 component audit

Read-only diagnostic over the already verified V2 R4 caches. It does not load,
replay, or train Stage-II. It separates Stage-I/global content from the 88-D
structural tail and reports paired 10,000-iteration bootstrap intervals.

It also adds the mathematically appropriate `abs(stage1_logit)` sanity baseline
for a magnitude target defined from `abs(stage1_logit)`.

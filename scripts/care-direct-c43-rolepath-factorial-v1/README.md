# CARE-Droid Direct-C43 RoleGraph path factorial v1

This source-only experiment is authorized by the strict matched RoleGraph–Host audit. It retrains the same Direct-C43 architecture under a fixed 2×2 intervention on two RoleGraph paths:

- RoleGraph token conditions Host/Relation query selection.
- RoleGraph token enters the final Direct-C43 readout slot.

Every arm keeps the same instantiated parameter set, outer folds, inner OOF Stage-I probabilities, SVM MeanOpposition Top25% route, seeds, threshold, features and training protocol. Only two non-trainable binary buffers differ. No future or external row is loaded.

The experiment is an attribution and simplification test, not permission to tune separate class thresholds or add another gate.

# CARE-Droid SVM Direct-C43 strict matched joint audit v1

This is a source-only attribution audit, not a new model. It replays the exact frozen SVM Direct-C43 model and repeats only the previously localized RoleGraph/Global24 correspondence interventions.

APK-level donors are matched without labels inside the same outer fold and Stage-I prediction direction. Frozen calipers constrain Stage-I probability, log Host count, and P31 Hellinger distance. Unmatched targets are retained, reported, and excluded from the conditional AUC decision. `N0_ROW_ORDER` remains the exact invariance control. No future/external row, new threshold, gate, readout, or separately trained arm is allowed.

This audit can localize model reliance or harmful attribution. It cannot prove causal Android program semantics. A new source ablation is allowed only when a relation passes the predeclared two-sided/per-fold diagnostic rule.

# CARE-Droid Formal v1

Immutable source-only freeze and characterization of:

`P31-RF -> RF-anchored MeanOpposition DI25 (25%) -> Role C43-RQ -> bounded correction`.

The package never loads future years or modifies the frozen method. A0/A2 are reconstructed from the locked prediction artifact. A1 uses five predeclared label-free random routes with the same per-fold count. A3 applies the already-saved bounded C43 candidate to every validation row. A4 is prohibited because no canonical pre-bound prediction was saved.

Cost reporting is deliberately conservative: post-cache decision operations are measured, but actual end-to-end runtime savings remain unauthorized unless compatible same-machine extraction and model-inference timing exists. The exact 200/799 versus 799/799 work-count comparison is reported separately and is never mislabeled as measured wall-time savings.

# CARE-Droid Host-local CFG / RoleGraph Witness All-Years Audit v2

This is a read-only 2017--2021 temporal audit of the frozen Host-local CFG
witness definition. It scans every available APK (2,788 total) and reports two
separate scopes: ALL APKs and the unchanged SVM MeanOpposition routed subsets
(697 total). It reuses the formal endpoint caches, Role31 mapping, frozen
Stage-I/Direct-C43 predictions and InterZ961 arrays.

The audit asks whether the high 2017 witness coverage, structural novelty and
lack of class direction persist across later years. It never trains a model,
changes a threshold, recomputes routing, installs or executes an APK, or writes
outside its new artifact directory.

Reliable malware-family labels are not available in the frozen assets.
Consequently, temporal consistency is reported separately and is never called
family independence. The all-APK scope is the primary coverage audit; the
routed scope is the deployment-relevant conditional audit.

# CARE-Droid Host-local CFG / RoleGraph Witness Pilot v1

This is a source-2017-only, read-only pilot. It reuses the frozen Host and
Role31 contracts and the already validated LCC-v2 DEX/exceptional-CFG engine,
but asks a distinct question: whether two sensitive call sites in the same
Host method have a verifiable local CFG relation not represented by the
existing APK-level Role statistics and InterZ961 channel.

The package never trains a model, never changes Stage-I/router/C43/backgrounds,
never reads 2018--2021 assets, and never installs or executes an APK.

Actual frozen route available on the server is the 2017 SVM MeanOpposition
Top25% route (200/799; 40 per fold), not a DI25-labelled route. This protocol
difference is fail-open only for documentation: membership is reused exactly
and never recomputed.

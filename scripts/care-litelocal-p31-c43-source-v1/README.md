# CARE-Droid strict-2017 P31 -> DI25 -> C43-RQ

This is the missing end-to-end source experiment. It uses only the 31-D P31
representation for Stage-I, the calibrated LR/RF/XGB/SVM mean probability,
fold-wise top-25% MeanOpposition routing, and the existing C43-RQ bounded
expert. It does not use FUSED63.

Leakage controls:

- outer-validation Stage-I probabilities are the locked strict OOF P31 values;
- outer-train Stage-I inputs to C43-RQ are regenerated by nested inner OOF;
- Stage-II backgrounds/scalers are fitted by the existing fold-safe C43 code;
- C43-RQ is trained on every outer-training APK and correction is applied only
  to the 40 routed validation APKs per fold;
- no future row, within-year row, or Ego tensor is loaded.

Global24 remains part of the expensive routed expert context. It is not the
Stage-I classifier and does not determine the P31-DI25 route.

Run from the repository root:

```bash
unzip -o ../care-litelocal-p31-c43-source-v1.zip -d scripts/
bash scripts/care-litelocal-p31-c43-source-v1/launch_tmux.sh
tail -F artifacts/care-litelocal-p31-c43-source-v1.console.log
```

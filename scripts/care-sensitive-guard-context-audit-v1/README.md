# CARE-Droid sensitive guard-context audit v1

This package performs a label-free feasibility pilot on 30 source-2017 APKs selected from the frozen P31-SVM MeanOpposition Top25% route.

It observes new static facts around Role31-sensitive invokes: framework-stable user/background callbacks, nearby conditional branches, and co-located permission, consent, or scheduling operations. Co-location is never called control dependence or runtime causality.

The pilot has a hard coverage gate. Failure stops the direction. Passing authorizes only a full 200-APK coverage audit, not training, threshold tuning, correction integration, or future-year testing.

No APK is rewritten or executed. No formal asset is modified. No future data or label is loaded during selection and coverage evaluation.
